# Lumière

Лендинг ИИ-видеостудии: Love Story, Архив жизни, Personal video, Commercial shorts.

Весь сайт — один файл `index.html` без сборки и зависимостей.
Шрифты подгружаются с Google Fonts, остальное внутри.

## Локальный запуск

```bash
python -m http.server 5173
```

Затем откройте http://localhost:5173

## Публикация

Любой статический хостинг. Достаточно выложить `index.html` в корень.
